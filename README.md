# 26-1ServerProgramming

## 주제

메뉴 추천 서비스

## 기술 스택

- Gradio
- FastAPI
- ngrok

## 구성

- Backend: FastAPI, LLM
- Frontend: Gradio

## 협업 방식

- Issue 기반으로 작업을 정의합니다.
- 작업별 Branch를 생성하여 개발합니다.
- Pull Request를 통해 코드 리뷰를 진행합니다.
- 리뷰 완료 후 `dev` 브랜치에 먼저 병합하여 테스트를 진행합니다.
- 테스트 완료 후 최종적으로 `main` 브랜치에 병합합니다.
